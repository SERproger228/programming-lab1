# Лабораторная работа 1

Тема: абстрактный тип данных на языке C.  
Вариант: многочлен с коэффициентами `int` и `double`.

## Структура

- `include/type_info.h` - описание типа элемента и операций над ним.
- `include/dynamic_array.h` - интерфейс динамического массива.
- `include/polynomial.h` - интерфейс многочлена.
- `src/type_info.c` - реализации операций для `int` и `double`.
- `src/dynamic_array.c` - реализация динамического массива.
- `src/polynomial.c` - реализация многочлена.
- `src/main.c` - консольная программа для ручной проверки.
- `tests/test_main.c` - простые тесты.

## Сборка

```bash
make
```

## Запуск

```bash
make run
```

## Тесты

```bash
make test
```
